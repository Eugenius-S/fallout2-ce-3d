# Regression fixed-screen reliability evidence

This directory records task 009 verification: focus-pause diagnosis, isolated config independence, and the 16-view reference update. The temporary SDL event injection and diagnostic logging were removed after the tests; they are not present in the committed source or shipped build.

`synthetic-focus-loss/` is the pre-fix reproduction. Its own test process queued and processed an SDL focus-loss event, entered `_GNW95_lost_focus` with `active=0`, and produced no snapshot before the 20-second launcher timeout. `synthetic-focus-loss-fixed/` is the same controlled test after the narrow fix: the event was processed, then the scene produced a PNG and JSON sidecar at 1920x1080, logical 960x540, scale 2, windowed. The output's EXE hash identifies the temporary diagnostic build, not the final production build.

The permanent fix skips focus deactivation only when fixed-screen options are enabled and `F2CE_DEV_BACKGROUND` is set. A normal or manually launched game still uses the original focus-loss handler. After removing the diagnostic code, the restored input source was rebuilt for both `fallout2-ce.exe` and `mapper-ce.exe`; the final source and game EXE were scanned for `F2CE_TEST_FOCUS_LOST` and `devdiag:` markers and contained neither. Final game EXE SHA-256: `AC826EC36586C311C9734D724BC47F85932D88089BDC3A9E7882298E7627B27D`.

Two earlier full reference updates stopped atomically: one at `klamall-e0`, one at `klatrap-e0`, each after 15 valid spots. Their checker summaries are retained in `failed-batch-klamall/` and `failed-batch-klatrap/`; isolated captures for both map/tile pairs succeeded in `debug-klamall/` and `debug-klatrap/`. The events were not instrumented at the time, so their specific cause is unknown. The reproduced focus-pause path demonstrates a real background-capture failure mode, but does not prove that it caused either historical timeout.

The three isolated input fixtures and their hash/timestamp records are in `fixture-proof.json`. Their captures all reported the requested fixed output mode and had identical decoded RGBA hashes; the owner config hash is recorded there. `fixture-proof/` retains one original PNG/JSON pair. `baseline-size-change/` retains one entrance view before (2310x1298) and after (1920x1080), with metadata. `regression-update/summary.txt` records the successful atomic update of all 16 refs, and `regression-normal/summary.txt` records the separate all-16 comparison with zero changed pixels. The JSON summaries retain each capture's actual metadata and image hash.
