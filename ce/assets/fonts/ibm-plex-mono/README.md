# IBM Plex Mono

Unmodified font files from the Google Fonts `ofl/ibmplexmono` directory:
https://github.com/google/fonts/tree/01d5d9f05246fb7090a8403b81257535cb1a088b/ofl/ibmplexmono

Pinned revision: `01d5d9f05246fb7090a8403b81257535cb1a088b`
(2026-09-28). License: SIL Open Font License 1.1, retained in `OFL.txt`.
SemiBold is the interface text weight; Bold is for titles. These TTF files
are the only font-data sources; the build generates C++ byte arrays from them.
